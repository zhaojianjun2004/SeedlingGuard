### 已核对的生成配置

- `.ioc` 芯片为 `STM32F407ZGT6`，CubeMX 版本 6.14.1，目标工具链 CMake/GCC。
- 时钟为 HSE 25 MHz、HCLK 168 MHz、APB1 42 MHz、APB2 84 MHz；`PLLM=25、PLLN=336、PLLP=2`。当前 `PLLQ=4`，对应 48 MHz 域实际 **84 MHz**；本版未启用 USB/SDIO，暂不影响上述接口，若以后用 48 MHz 外设应先改成 `PLLQ=7` 并重新检查时钟树。
- `PC0` 初始低、`PG6` 初始高；SPI1 为 `PB3/PB4/PB5`、CPOL 高/CPHA 第二边沿；USART2 和 USART3 的 DMA、UART 全局中断与 TIM6 中断均已生成。
- CAN2 现已加入 `.ioc` 和生成代码：Normal 模式、`Prescaler=21`、`BS1=12TQ`、`BS2=3TQ`、`SJW=1TQ`，RX0 IRQ 优先级 5、SCE IRQ 优先级 6。`HAL_CAN_MspInit()` 已调用 `__HAL_RCC_CAN1_CLK_ENABLE()`，不需要手工重复加时钟。当前自动重传为 Disabled，由后续应用做有上限重试。
- USART1 调试串口现已加入生成工程；USART2/3、DMA、SPI1 与 TIM6 的配置均保持正常。
- `FreeRTOSConfig.h` 实际为 `configMAX_PRIORITIES=56`、`configTOTAL_HEAP_SIZE=32768`、`configTICK_RATE_HZ=1000`、`configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY=5`。`.ioc` 的 `MAX_CO_ROUTINE_PRIORITIES=2` 是**协程**设置，当前 `configUSE_CO_ROUTINES=0`；不能据此改任务最大优先级。
- `.ioc` 与 `freertos.c` 已同步为 `linkTask`、`fieldTask`、`modbusTask`、`supervisorTask` 四个空任务，栈分别为 512、512、768、256 words。多余 `defaultTask` 已移除，`StartFieldTask` 拼写已修正；任务创建后增加了非空断言。任务暂以 1 s 间隔空转，业务代码尚未接入。

### 下一步仍需实现或核对

1. **CAN2 只有外设初始化，尚无业务收发。** 应用层还需配置 CAN2 filter bank 14、调用 `HAL_CAN_Start()` 和 `HAL_CAN_ActivateNotification()`，实现 RX/错误回调及有上限重试，然后与 USB-CAN 实机联调。
2. **UART/Modbus 只有外设与 DMA 配置。** 两路 RX DMA 尚未由应用启动，板间 UART 帧解析、Modbus 事务、测点质量和实际控制状态都尚未实现。
3. **下次 CubeMX 再生成需复核任务表。** 本次为消除冗余任务和拼写问题，已同时修改 `.ioc` 的 `FREERTOS.Tasks01` 与生成的 `freertos.c`；若 CubeMX 窗口仍保留旧的内存配置，先关闭并重新打开 `.ioc` 再生成，避免覆盖这次同步结果。
4. **路径与固件包记录需统一。** 实际目录是 `fireware/`；`.ioc` 同时记录 FirmwarePackage `V1.28.3` 和 CustomerFirmwarePackage 指向 `V1.28.0` 的路径。现有代码可编译，但下次再生成前要确认 CubeMX 选中的固件包。

旁边的 `F:\tools\learn\stm32\文档\嵌入式项目\机器人\测距与红外循迹\Docs\USB转CAN模块商品图.jpg` 显示 USB-CAN 外壳标注“隔离型”、CAN H/L 接线端子和 `120R` 开关；商品图只能辅助识别，实际接线及开关位置以手中模块丝印为准。说明书第 11 页展示的 PCAN-View **默认 500 kbps**，本工程 CAN2 为 **125 kbps**，连接前务必手动改成相同波特率。

当前双板 UART 已接 `F407 PD8/TX → ESP32 GPIO18/RX`、`F407 PD9/RX ← ESP32 GPIO17/TX`，**还缺 F407 GND ↔ ESP32 GND**。两板可以分别通过各自 USB 供电；UART 是非隔离 3.3 V TTL 信号，仍需短 GND 线建立共同电平参考，不能依赖电脑内部 USB 地线绕行。只在 F407 底板 J40 的指定 1–2 电源跳帽连接板载 3V3 与 CAN/485_3V3；这与两板 UART 共地是两件事，不要再把两块板的 3V3 电源脚相连。接线前断开两板电源，接好 GND 后再上电验证。
